It even shows your backups. What is knowledge worth if it can be destroyed?

Every usage tracker stops at the numbers. Claude Usage Monitor goes one step further: it also shows whether your Claude-related backups are fresh – your skills, CLAUDE.md rules, project memory, MCP settings, agent conversation logs and Obsidian notes. They usually live on one single disk. One broken drive, one stolen laptop, one wrong delete – and months of work are gone. Three small lamps on the panel tell you, every minute of the day, that it can't happen to you.

Three lamps. One look. You know.

  • Green – the last successful backup is at most 24 hours old.
  • Yellow – it is 24 to 48 hours old. Time to look.
  • Red – older than 48 hours, or there is no backup at all.
  • Red ring – the latest run failed or did not finish, even if an older backup still keeps the lamp green.

The lamps are OneDrive (first copy), Nextcloud (second, independent cloud – any cloud rclone supports works) and Obsidian (dated snapshot of your vault). Only a run that really finished counts: a failed, interrupted or test run never turns a lamp green. The hours are adjustable. Click any lamp for the details.

Help: set up a backup the monitor can show

Open only what you need. Every step is here – what to use, what to set, what to click. The kit is a starting point you can change – please read the disclaimer above.

Set it up in 10 minutes – step by step
  1. What you need. Windows 10 or 11, OneDrive signed in, Claude Usage Monitor installed. For the second copy: a Nextcloud account – or any other cloud rclone supports (Google Drive, Dropbox, S3, pCloud, SFTP…). No second cloud? Step 2 is optional.
  2. Create an app password (only for the second cloud). In Nextcloud: your avatar → Personal settings → Security → Devices & sessions → app name rclone-backup → Create new app password. Copy it – it is shown only once. It is not your account password, and you can revoke it at any time.
  3. Download and unpack the Backup Kit into a permanent folder, for example C:\Tools\ClaudeBackup.
  4. Edit config.psd1 in Notepad: VaultPath = your Obsidian vault (empty = no Obsidian), ExtraFolders = anything else to back up, NextcloudRemote and NextcloudBasePath = the second cloud (empty = skip it), DailyTime = when to run. Everything else can stay as it is.
  5. Run the installer as administrator: Win+X → Terminal (Admin), then Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, cd C:\Tools\ClaudeBackup, Unblock-File *.ps1, .\Install-BackupKit.ps1. It installs rclone if needed, asks for the cloud address, user name and app password (typed hidden), creates the two scheduled tasks, tells the monitor where to look and makes a first run.
  6. First real upload:.\Backup-Step2-Cloud.ps1 – the installer only made a test run of step 2.
  7. Check it:.\Test-BackupKit.ps1 – every line should say [OK]. In Claude Usage Monitor: right-click the panel → Backup status bar. The three lamps turn green within 5 minutes, or at once with Backups… → Check now.
What gets backed up – and what never does
  • Claude Code (%USERPROFILE%\.claude) – skills, settings, CLAUDE.md, project memory, plugins.
  • Claude Desktop (%APPDATA%\Claude) – settings and MCP servers.
  • Agent conversation logs – one ZIP per session.
  • Obsidian vault – a dated ZIP snapshot at every run, kept for 30 days.
  • Your extra folders – whatever you list in config.psd1.
  • Never: the Claude Code sign-in token (.credentials.json), Claude Desktop's cookies, caches and the large, re-downloadable VM images.

Security – how the kit protects your data
  • No password in any file of the kit. The app password is typed hidden and stored only in rclone's own configuration, obscured. Revoke it in Nextcloud whenever you like.
  • The sign-in token is never copied. Nor are Claude Desktop's cookies.
  • No mirroring. A file you delete on your computer stays in both backups – mirroring would faithfully copy a mistake too.
  • Dated vault snapshots, so a later bad copy can never overwrite an older good state.
  • Two independent providers. If one fails or locks you out, the other still has everything.
  • Good to know: Claude Desktop's config and .claude\settings.json may hold API keys of MCP servers. They are backed up – you need them to restore – into your own OneDrive and your own cloud. Protect both accounts with two-step sign-in.

Already have your own backup? What the monitor needs
  • A log per run in the logs subfolder of your backup folder, named onedrive_YYYY-MM-DD_HHMMSS.log and nextcloud_…log, every line starting with the date and time.
  • A clear ending: a successful run ends with a line containing KESZ, a failed one with HIBAVAL ZARULT. The kit's Common.ps1 documents every word the monitor understands.
  • Where to look: set the Backup folder on the Backups tab. Different folder or file names can be set in backup_profile.json – the kit's README shows how.
  • Mac: the lamps read the same logs on macOS too; the kit itself and the scheduled-task list are for Windows.

What is Claude Usage Monitor?

Claude Usage Monitor is a free, open-source desktop widget for Windows 10/11 and macOS that shows your Claude subscription's usage limits in real time – the five-hour session, the weekly limit and the per-model weekly limit, each with the time left until it resets. It stays on top of your other windows, so you can check your Claude usage without opening Settings → Usage and without a terminal.

One app for both Windows and Mac. It covers everything that counts toward your plan – claude.ai, Claude Desktop and Claude Code, on all your devices. It is not the terminal tool “Claude Code Usage Monitor”: this one is a graphical panel with a tray icon, and needs no command line.

Last updated: 2026-09-21 · Version 2.6.2 · by Vidovics Gábor

Key terms, precisely defined
Five-hour session (5-hour window)
Claude's short-term usage limit. Your session-based limit resets every five hours. Anthropic calls it the “current session”; many users call it the 5-hour window or 5-hour limit.
Weekly limit
A second cap on paid Claude plans that applies across all models and resets at a fixed time each week, assigned to your account. Weekly limits have been in effect since 28 August 2025.
Per-model weekly limit
A separate weekly cap for one specific model, listed on Claude's usage page next to the limit for all other models. The widget shows it as a third gauge for the model you choose.
Reset
The moment a limit goes back to 0%. The widget counts down to it. With claude.ai sign-in the exact time comes from Anthropic's server; with the local log it is an estimate.
Pace
How far you are ahead of or behind an evenly used week. “+12% vs pace” means you have used 12 percentage points more of your weekly limit than the share of the week that has passed.
Burn rate
How fast a limit is filling up right now – percent per hour for the session, percent per day for the week – and when it would reach 100% at that speed.
Usage credits (extra usage)
Optional pay-as-you-go usage after you reach your plan's limits, with a monthly spending cap. The widget shows whether it is switched on, the cap and what you have spent.

FAQ

Questions about Claude usage limits – short answers.

Is it really free? What's the catch?

Really free, and there is no catch. It's not a demo, not a trial and not a cut-down edition – this is the full and only version. No ads, no paid tier, no data collection. The source code is public under the MIT licence.

How do I check my Claude usage without opening Settings?

Install Claude Usage Monitor: it keeps your five-hour session, weekly limit and per-model limit on screen all the time, as a small always-on-top widget and as a percentage in the tray or menu bar. Claude's own numbers live under Settings → Usage; the widget shows the same limits without any clicking.

When do the Claude 5-hour session and the weekly limit reset?

The session-based limit resets every five hours. The weekly limit resets at a fixed time each week that Anthropic assigns to your account, so it differs from person to person. The widget shows a live countdown to both resets – with claude.ai sign-in it uses the exact times from Anthropic's server.

Does Claude Code usage count toward my claude.ai limit?

Yes. According to Anthropic, usage on claude.ai, Claude Desktop and Claude Code counts toward the same usage limit. That is why the widget's claude.ai mode shows one number for all your devices and apps, not only for the computer it runs on.

Is this the same as “Claude Code Usage Monitor”?

No. “Claude Code Usage Monitor” is a separate, terminal-based tool by another author. Claude Usage Monitor by Vidovics Gábor is a graphical desktop widget for Windows and macOS with a tray icon, themes and alerts, and it needs no command line.

Can Claude Usage Monitor show whether my Claude files are backed up?

Yes – and it is free as well. With the backup status bar switched on, three lamps on the panel show whether the backup to OneDrive, to a second cloud such as Nextcloud and of your Obsidian vault is fresh: green up to 24 hours, yellow up to 48, red when it is older or missing, and a red ring when the latest run failed. The monitor only reads the backup logs; the backup itself is made by the free Claude Backup Kit, which copies your Claude Code skills, CLAUDE.md, project memory, Claude Desktop settings and agent logs every day – never the sign-in token. The kit is a free starting point that anyone can change, so we accept no liability for backups: making sure they are complete and can be restored is up to each user.

Is this an official Anthropic product?

No. It's an independent community tool made by Vidovics Gábor. It is not affiliated with Anthropic. “Claude” is a trademark of Anthropic, PBC.

Do I have to give it my password?

Never. Without signing in it reads Claude Desktop's local log. If you want all devices, you sign in on claude.ai in your own browser – the app never sees your password.

Windows warns me when I run it. Why?

Because the app isn't code-signed (certificates cost money; the app is free). Click More info → Run anyway. You can verify the download with its SHA-256 checksum, and read the source on GitHub.

Which Macs are supported?

macOS 12 or newer. The download card above always shows which processor the current build is for. The macOS version is new – feedback is very welcome.

How do updates work?

The app checks this site a few times a day. When there's a new version it tells you; one click downloads, verifies and installs it, then restarts. You can switch this off.

How do I remove it?

Windows: Settings → Apps → Installed apps → Claude Usage Monitor → Uninstall. macOS: drag the app to the Bin. That's all.
