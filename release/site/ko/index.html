백업 상태까지 보여 줘요. 한순간에 날아갈 수 있는 지식, 그 가치는 얼마일까요?

다른 사용량 추적 도구는 숫자에서 멈춰요. Claude Usage Monitor는 한 걸음 더 나아가 Claude 관련 백업이 최신인지도 보여 줘요. 스킬, CLAUDE.md 규칙, 프로젝트 메모리, MCP 설정, 에이전트 대화 로그, Obsidian 노트까지요. 이런 파일은 대개 디스크 하나에만 들어 있어요. 드라이브 고장, 노트북 도난, 실수로 한 삭제 한 번이면 몇 달 치 작업이 사라져요. 패널의 작은 표시등 세 개가 하루 종일, 매 순간 그런 일은 없다고 알려 줘요.

표시등 세 개. 한 번 보면 바로 알아요.

  • 녹색 – 마지막 성공 백업이 24시간 이내예요.
  • 노란색 – 24~48시간 전이에요. 한번 살펴볼 때예요.
  • 빨간색 – 48시간보다 오래됐거나 백업이 아예 없어요.
  • 빨간 테두리 – 가장 최근 실행이 실패했거나 끝나지 않았어요. 이전 백업 덕분에 표시등이 아직 녹색이어도 마찬가지예요.

표시등은 OneDrive(첫 번째 사본), Nextcloud(서로 독립된 두 번째 클라우드 – rclone이 지원하는 클라우드라면 무엇이든 가능), Obsidian(보관소의 날짜별 스냅샷)이에요. 실제로 끝까지 완료된 실행만 인정돼요. 실패했거나 중단된 실행, 테스트 실행으로는 표시등이 절대 녹색이 되지 않아요. 기준 시간은 바꿀 수 있어요. 표시등을 클릭하면 자세한 내용이 보여요.

Claude Usage Monitor + 무료 Backup Kit

  • 실패하거나 끝나지 않은 실행을 즉시 표시
  • 무엇을, 어디에, 파일 몇 개를, 얼마만큼 백업했는지
  • 예약된 작업과 로그 – 클릭 한 번이면 확인

표시등을 클릭하면 이런 내용이 보여요

  • 상태 – 최신, 조금 오래됨, 오래됨, 백업 없음 중 하나와 함께 마지막 성공 백업 시각과 마지막 실행 시각.
  • 백업 항목 – 항목마다 원본 폴더, 대상, 파일 수, 크기: Obsidian 보관소 스냅샷, Claude Code, Claude Desktop, 추가 폴더, 에이전트 로그.
  • 내용 – 가장 최근 보관소 스냅샷, 보관 중인 스냅샷 수, 최근에 편집한 노트, 마지막 스냅샷 이후 바뀐 노트 수.
  • 업로드 – Nextcloud 탭에서: 이번 실행에서 새로 올리거나 교체한 파일(폴더별)과 클라우드의 남은 공간.
  • 오류 및 경고 – 로그에서 바로 가져와 알기 쉬운 말로.
  • 예약된 작업 – 백업을 실행하는 Windows 작업의 상태, 마지막 결과, 다음 실행 시각.
  • 로그 – 마지막 몇 줄, 그리고 클릭 한 번으로 여는 로그 파일.

모니터는 읽기만 해요. 파일을 바꾸거나 옮기거나 업로드하는 일은 절대 없어요. 5분마다 다시 확인하고, “지금 확인”을 누르면 바로 확인해요. OneDrive에 온라인 전용으로만 있는 스냅샷은 목록을 보여 주려고 일부러 내려받지 않아요.

무료 솔직히 말하면: 모니터는 지켜보고, 백업은 키트가 해요.

Claude Usage Monitor는 파일을 복사하지 않아요. 복사가 제대로 됐는지 보여 줄 뿐이에요. 복사는 Claude Backup Kit이 맡아요. 한 줄 한 줄 읽어 볼 수 있는 짧은 PowerShell 스크립트 몇 개로 되어 있어요. 매일 Claude 작업을 OneDrive와 서로 독립된 두 번째 클라우드에 백업하고, 표시등이 읽는 로그를 남겨요. 계정도, 구독도 필요 없고, 저희에게 전송되는 것도 없어요.

면책 조항 – 꼭 읽어 주세요

백업, 데이터 손실 또는 그 밖의 어떠한 손해에 대해서도 책임을 지지 않습니다. Claude Usage Monitor는 백업 로그를 읽어 표시할 뿐이며, 어떤 백업도 생성하거나 검사하거나 보장하지 않습니다. Claude Backup Kit은 도움을 드리고자 무료로 제공하는 출발점일 뿐, 완성된 제품이 아닙니다. 누구나 자신의 컴퓨터에 맞게 스크립트를 수정할 수 있고 또 수정해도 되므로, 백업의 품질과 완전성은 보장할 수 없습니다. 백업이 완전하고 복원 가능한지 확인하는 것은 각자의 책임입니다. 표시등을 확인하고, 로그를 읽고, 때때로 복원을 직접 테스트해 보시기 바랍니다. 키트는 MIT 라이선스에 따라 어떠한 보증도 없이 “있는 그대로” 제공됩니다.

필요한 부분만 펼쳐 보세요. 무엇을 쓰고, 무엇을 설정하고, 어디를 클릭할지 모든 단계가 여기 있어요. 키트는 얼마든지 고쳐 쓸 수 있는 출발점이에요. 위의 면책 조항을 꼭 읽어 주세요.

10분이면 설정 끝 – 단계별 안내
  1. 준비물. Windows 10 또는 11, 로그인된 OneDrive, 설치된 Claude Usage Monitor. 두 번째 사본용으로는 Nextcloud 계정 – 또는 rclone이 지원하는 다른 클라우드(Google Drive, Dropbox, S3, pCloud, SFTP…)가 필요해요. 두 번째 클라우드가 없다면 2단계는 건너뛰어도 돼요.
  2. 앱 비밀번호 만들기(두 번째 클라우드에만 해당). Nextcloud에서: 내 아바타 → 개인 설정 → 보안 → 기기 및 세션 → 앱 이름 rclone-backup → 새 앱 암호 만들기. 한 번만 표시되니 바로 복사하세요. 계정 비밀번호가 아니며, 언제든지 취소할 수 있어요.
  3. 다운로드 후 압축 풀기 – Backup Kit을 계속 둘 폴더에 풀어 주세요. 예: C:\Tools\ClaudeBackup.
  4. config.psd1 편집 – 메모장에서: VaultPath = Obsidian 보관소(비워 두면 Obsidian 없음), ExtraFolders = 그 밖에 백업할 폴더, NextcloudRemote와 NextcloudBasePath = 두 번째 클라우드(비워 두면 건너뜀), DailyTime = 실행 시각. 나머지는 그대로 두면 돼요.
  5. 관리자 권한으로 설치 프로그램 실행: Win+X → 터미널(관리자)을 연 다음 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, cd C:\Tools\ClaudeBackup, Unblock-File *.ps1, .\Install-BackupKit.ps1. 필요하면 rclone을 설치하고, 클라우드 주소와 사용자 이름, 앱 비밀번호(입력 내용은 숨겨짐)를 묻고, 예약된 작업 두 개를 만들고, 모니터에 확인할 위치를 알려 준 뒤 첫 실행까지 마쳐요.
  6. 첫 실제 업로드:.\Backup-Step2-Cloud.ps1 – 설치 프로그램은 2단계를 테스트로만 실행했어요.
  7. 확인하기:.\Test-BackupKit.ps1 – 모든 줄에 [OK]가 나와야 해요. Claude Usage Monitor에서: 패널을 오른쪽 클릭 → 백업 상태 표시줄. 5분 안에 표시등 세 개가 녹색으로 바뀌고, 백업… → 지금 확인을 누르면 바로 바뀌어요.
백업되는 것 – 그리고 절대 백업되지 않는 것
  • Claude Code(%USERPROFILE%\.claude) – 스킬, 설정, CLAUDE.md, 프로젝트 메모리, 플러그인.
  • Claude Desktop(%APPDATA%\Claude) – 설정과 MCP 서버.
  • 에이전트 대화 로그 – 세션마다 ZIP 하나.
  • Obsidian 보관소 – 실행할 때마다 날짜가 붙은 ZIP 스냅샷, 30일간 보관.
  • 추가 폴더 – config.psd1에 적은 폴더 전부.
  • 절대 백업하지 않는 것: Claude Code 로그인 토큰(.credentials.json), Claude Desktop의 쿠키와 캐시, 다시 내려받을 수 있는 대용량 VM 이미지.

세부 정보 창에 표시보고 싶은 항목을 선택하세요: 백업 항목, 내용, 오류 및 경고, 예약된 작업, 로그.

설치 프로그램은 %APPDATA%\ClaudeUsageMonitor\backup_profile.json 파일을 만들어요 – 폴더 경로만 들어 있고, 비밀번호나 토큰은 없어요. 백업 탭에서 설정한 값이 이 파일보다 우선해요.

보안 – 키트가 데이터를 지키는 방법
  • 키트의 어떤 파일에도 비밀번호가 없어요. 앱 비밀번호는 화면에 표시되지 않게 입력되고, rclone 자체 구성에만 난독화되어 저장돼요. Nextcloud에서 언제든지 취소할 수 있어요.
  • 로그인 토큰은 절대 복사하지 않아요. Claude Desktop의 쿠키도 마찬가지예요.
  • 미러링하지 않아요. 컴퓨터에서 삭제한 파일도 두 백업에는 그대로 남아요 – 미러링은 실수까지 충실히 복사하니까요.
  • 날짜별 보관소 스냅샷 덕분에 나중에 잘못된 사본이 이전의 정상 상태를 덮어쓸 수 없어요.
  • 서로 독립된 두 업체. 한쪽에 장애가 생기거나 계정이 잠겨도 다른 쪽에 모든 것이 남아 있어요.
  • 알아 두세요: Claude Desktop 구성과 .claude\settings.json에는 MCP 서버의 API 키가 들어 있을 수 있어요. 복원할 때 필요하므로 이 파일도 내 OneDrive와 내 클라우드에 백업돼요. 두 계정 모두 2단계 인증으로 보호하세요.
복원 – 필요할 때
노트의 이전 버전onedrive.com → 파일을 오른쪽 클릭 → 버전 기록.
삭제한 파일OneDrive 휴지통(30일) 또는 Nextcloud 삭제된 파일.
특정 날짜의 보관소 전체vault-snapshots\Vault_…zip을 빈 폴더에 압축 해제한 뒤 Obsidian에서 여세요: 폴더를 보관소로 열기.
Claude Code 스킬과 설정files\claude-code를 %USERPROFILE%\.claude로 다시 복사한 뒤 Claude Code에 다시 로그인하세요.
Claude Desktop 설정Claude Desktop을 닫고 files\claude-desktop을 %APPDATA%\Claude로 다시 복사하세요.
이미 쓰는 백업이 있나요? 모니터에 필요한 것
  • 실행마다 로그 하나 – 백업 폴더의 logs 하위 폴더에 onedrive_YYYY-MM-DD_HHMMSS.log, nextcloud_…log 형식의 이름으로 두고, 모든 줄은 날짜와 시각으로 시작해야 해요.
  • 분명한 끝 표시: 성공한 실행은 KESZ가 들어간 줄로, 실패한 실행은 HIBAVAL ZARULT가 들어간 줄로 끝나야 해요. 모니터가 알아듣는 모든 단어는 키트의 Common.ps1에 정리되어 있어요.
  • 확인할 위치: 백업 탭에서 백업 폴더를 지정하세요. 폴더나 파일 이름이 다르면 backup_profile.json에서 설정할 수 있어요 – 방법은 키트의 README에 있어요.
  • Mac: macOS에서도 표시등은 같은 로그를 읽어요. 키트 자체와 예약된 작업 목록은 Windows 전용이에요.

Claude Usage Monitor란?

Claude Usage Monitor는 Claude(클로드) 구독의 사용 한도를 실시간으로 보여 주는 Windows 10/11 및 macOS용 무료 오픈 소스 데스크톱 위젯이에요 – 5시간 세션, 주간 한도, 모델별 주간 한도를 각각 초기화까지 남은 시간과 함께 보여 줘요. 다른 창 위에 항상 떠 있어서, 설정 → 사용량을 열지 않아도, 터미널 없이도 Claude 사용량을 확인할 수 있어요.

Windows와 Mac 모두 앱 하나로 써요. claude.ai, Claude Desktop, Claude Code 등 플랜 사용량에 포함되는 모든 것을 내 모든 기기에서 합산해요. 터미널 도구인 “Claude Code Usage Monitor”와는 다른 프로그램이에요. 이 앱은 알림 영역 아이콘이 있는 그래픽 패널이고, 명령줄이 필요 없어요.

Claude의 단기 사용 한도예요. 세션 기반 한도는 5시간마다 초기화돼요. Anthropic은 이를 “현재 세션”이라고 부르고, 많은 사용자는 5시간 제한이나 5시간 윈도우라고도 해요.
주간 한도
유료 Claude 플랜에 적용되는 두 번째 한도로, 모든 모델에 걸쳐 적용되며 계정마다 정해진 매주 같은 시각에 초기화돼요. 주간 한도는 2025년 8월 28일부터 시행되고 있어요.
모델별 주간 한도
특정 모델 하나에만 적용되는 별도의 주간 한도로, Claude 사용량 페이지에서 다른 모든 모델의 한도 옆에 표시돼요. 위젯은 선택한 모델의 한도를 세 번째 게이지로 보여 줘요.
초기화(리셋)
한도가 다시 0%로 돌아가는 시점이에요. 위젯은 그때까지 카운트다운해요. claude.ai에 로그인하면 Anthropic 서버에서 정확한 시각을 받아 오고, 로컬 로그를 쓰면 추정치예요.
페이스
한 주를 고르게 썼을 때와 비교해 얼마나 앞서 있거나 뒤처져 있는지를 나타내요. “페이스 대비 +12%”는 한 주 중 지나간 시간의 비율보다 주간 한도를 12%포인트 더 많이 썼다는 뜻이에요.
소모율
지금 한도가 얼마나 빠르게 차오르는지를 나타내요. 세션은 시간당 %, 주간 한도는 하루당 %로 보여 주고, 이 속도라면 언제 100%에 도달하는지도 알려 줘요.
사용량 크레딧(추가 사용량)
플랜 한도에 도달한 뒤에도 쓴 만큼 비용을 내고 계속 쓸 수 있는 선택형 사용량으로, 월간 지출 한도를 정할 수 있어요. 위젯은 켜져 있는지, 지출 한도, 지금까지 쓴 금액을 보여 줘요.

FAQ

Claude 사용 한도에 관한 질문 – 짧은 답변.

정말 무료예요? 숨은 조건은 없나요?

정말 무료이고, 숨은 조건도 없어요. 데모도, 체험판도, 기능을 뺀 버전도 아니에요 – 이게 완전한 유일한 버전이에요. 광고도, 유료 버전도, 데이터 수집도 없어요. 소스 코드는 MIT 라이선스로 공개되어 있어요.

설정을 열지 않고 Claude 사용량을 확인하려면 어떻게 하나요?

Claude Usage Monitor를 설치하세요. 5시간 세션, 주간 한도, 모델별 한도를 항상 위에 떠 있는 작은 위젯과 알림 영역 또는 메뉴 막대의 퍼센트로 늘 화면에 보여 줘요. Claude 자체의 수치는 설정 → 사용량에 있지만, 위젯은 같은 한도를 클릭 한 번 없이 보여 줘요.

Claude 5시간 세션과 주간 한도는 언제 초기화되나요?

세션 기반 한도는 5시간마다 초기화돼요. 주간 한도는 Anthropic이 계정마다 정한 매주 같은 시각에 초기화되므로 사람마다 달라요. 위젯은 두 초기화까지 남은 시간을 실시간으로 카운트다운하고, claude.ai에 로그인하면 Anthropic 서버의 정확한 시각을 사용해요.

Claude Code 사용량도 claude.ai 한도에 포함되나요?

네. Anthropic에 따르면 claude.ai, Claude Desktop, Claude Code에서의 사용량은 모두 같은 사용 한도에 포함돼요. 그래서 위젯의 claude.ai 모드는 위젯이 실행 중인 컴퓨터뿐 아니라 모든 기기와 앱을 합친 숫자 하나를 보여 줘요.

“Claude Code Usage Monitor”와 같은 프로그램인가요?

아니요. “Claude Code Usage Monitor”는 다른 개발자가 만든 별개의 터미널 기반 도구예요. Vidovics Gábor가 만든 Claude Usage Monitor는 알림 영역 아이콘, 테마, 알림을 갖춘 Windows·macOS용 그래픽 데스크톱 위젯이고, 명령줄이 필요 없어요.

Claude Usage Monitor를 평가하거나 의견을 보내려면 어떻게 하나요?

패널을 오른쪽 클릭하고 “개발자에게 메시지 보내기…”를 선택하거나, 패널 머리글의 메시지 아이콘을 클릭하세요. 별 1~5개로 평가하고 메시지를 쓸 수 있으며, 직접 체크한 경우에만 평가와 이름이 이 웹사이트에 표시돼요. 모든 메시지는 제작자 Vidovics Gábor가 직접 읽고, 동의 없이는 아무것도 게시하지 않아요. 앱이 없다면 이 페이지 맨 아래의 양식을 이용하세요.

Claude Usage Monitor는 어떤 언어를 지원하나요?

34개 언어를 지원해요. 유럽연합의 모든 공식 언어에 일본어, 한국어, 중국어 간체와 번체, 인도네시아어, 베트남어가 더해지고, 포르투갈어는 유럽과 브라질, 스페인어는 스페인과 중남미 버전이 따로 있어요. 앱은 시스템 언어를 자동으로 선택하며, 이 웹사이트도 이 모든 언어로 제공돼요.

Claude Pro, Max, Team, Enterprise에서도 작동하나요?

네. 내 Claude 플랜의 한도를 그대로 보여 줘요 – Pro, Max 5×, Max 20×, Team, Enterprise 모두요. Claude가 설정 → 사용량에 표시하는 것과 같은 한도이고, 패널 머리글의 플랜 배지를 보면 지금 어떤 플랜인지도 알 수 있어요.

Claude Usage Monitor로 Claude 파일이 백업됐는지 알 수 있나요?

네 – 이것도 무료예요. 백업 상태 표시줄을 켜면 패널의 표시등 세 개가 OneDrive 백업, Nextcloud 같은 두 번째 클라우드 백업, Obsidian 보관소 백업이 최신인지 보여 줘요. 24시간 이내면 녹색, 48시간 이내면 노란색, 더 오래됐거나 없으면 빨간색이고, 가장 최근 실행이 실패하면 빨간 테두리가 표시돼요. 모니터는 백업 로그를 읽기만 하고, 백업 자체는 무료 Claude Backup Kit이 해요. 키트는 Claude Code 스킬, CLAUDE.md, 프로젝트 메모리, Claude Desktop 설정, 에이전트 로그를 매일 복사하며, 로그인 토큰은 절대 복사하지 않아요. 키트는 누구나 수정할 수 있는 무료 출발점이므로 백업에 대해서는 책임을 지지 않아요. 백업이 완전하고 복원 가능한지 확인하는 것은 각 사용자의 책임이에요.

Anthropic 공식 제품인가요?

아니요. Vidovics Gábor가 만든 독립 커뮤니티 도구이며, Anthropic과 제휴 관계가 없어요. “Claude”는 Anthropic, PBC의 상표예요.

비밀번호를 입력해야 하나요?

절대 아니에요. 로그인하지 않으면 Claude Desktop의 로컬 로그를 읽어요. 모든 기기의 사용량을 보고 싶다면 내 브라우저에서 claude.ai에 로그인하면 돼요 – 앱은 비밀번호를 절대 보지 못해요.

실행하면 Windows가 경고를 띄워요. 왜 그런가요?

앱에 코드 서명이 되어 있지 않기 때문이에요(인증서는 유료인데 앱은 무료니까요). 추가 정보 → 실행을 클릭하세요. 다운로드한 파일은 SHA-256 체크섬으로 검증할 수 있고, GitHub에서 소스 코드도 확인할 수 있어요.

어떤 Mac을 지원하나요?

macOS 12 이상이에요. 위의 다운로드 카드에 현재 빌드가 어떤 프로세서용인지 항상 표시돼요. macOS 버전은 나온 지 얼마 안 됐으니 의견을 보내 주시면 큰 도움이 돼요.

업데이트는 어떻게 되나요?

앱이 하루에 몇 번 이 사이트를 확인해요. 새 버전이 있으면 알려 주고, 클릭 한 번으로 다운로드·검증·설치한 뒤 다시 시작해요. 이 기능은 끌 수 있어요.

삭제하려면 어떻게 하나요?

Windows: 설정 → 앱 → 설치된 앱 → Claude Usage Monitor → 제거. macOS: 앱을 휴지통으로 끌어다 놓으세요. 그게 다예요.
