10 分钟完成设置——分步说明
  1. 准备工作。Windows 10 或 11，已登录 OneDrive，已安装 Claude Usage Monitor。第二份副本需要：一个 Nextcloud 账户——或 rclone 支持的任何其他云存储（Google Drive、Dropbox、S3、pCloud、SFTP…）。没有第二个云盘？第 2 步可以跳过。
  2. 创建应用密码（仅第二个云盘需要）。在 Nextcloud 中：你的头像 → 个人设置 → 安全 → 设备与会话 → 应用名称 rclone-backup → 创建新应用密码。复制它——它只显示一次。它不是你的账户密码，你可以随时撤销。
  3. 下载并解压 Backup Kit 到一个固定的文件夹，例如 C:\Tools\ClaudeBackup。
  4. 用记事本编辑 config.psd1：VaultPath = 你的 Obsidian 仓库（留空 = 不使用 Obsidian），ExtraFolders = 其他要备份的内容，NextcloudRemote 和 NextcloudBasePath = 第二个云盘（留空 = 跳过），DailyTime = 每天的运行时间。其他保持不变即可。
  5. 以管理员身份运行安装程序：Win+X → 终端管理员，然后依次运行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned、cd C:\Tools\ClaudeBackup、Unblock-File *.ps1、.\Install-BackupKit.ps1。它会在需要时安装 rclone，询问云端地址、用户名和应用密码（输入时隐藏），创建两个计划任务，告诉本程序去哪里查看，并进行首次运行。
  6. 首次正式上传：.\Backup-Step2-Cloud.ps1——安装程序只对第 2 步做了一次测试运行。
  7. 检查：.\Test-BackupKit.ps1——每一行都应显示 [OK]。在 Claude Usage Monitor 中：右键点击面板 → 备份状态栏。三盏指示灯会在 5 分钟内变绿，或者点击 备份… → 立即检查 立刻变绿。

安全——工具包如何保护你的数据
  • 工具包的任何文件中都没有密码。应用密码以隐藏方式输入，仅以混淆形式保存在 rclone 自己的配置中。你可以随时在 Nextcloud 中撤销它。
  • 登录令牌绝不会被复制。Claude Desktop 的 Cookie 也不会。
  • 不做镜像同步。你在电脑上删除的文件，在两份备份中都会保留——镜像同步会把误操作也原样复制过去。
  • 带日期的仓库快照，之后出错的副本永远无法覆盖较早的正确状态。
  • 两个独立的服务商。即使其中一个出故障或锁定了你的账户，另一个仍保有全部内容。
  • 值得注意：Claude Desktop 的配置和 .claude\settings.json 中可能包含 MCP 服务器的 API 密钥。它们会被备份（恢复时需要），存入你自己的 OneDrive 和你自己的云盘。请为这两个账户开启两步验证。

Claude Usage Monitor 是什么？

Claude Usage Monitor 是一款免费、开源的桌面小组件，适用于 Windows 10/11 和 macOS，可实时显示你的 Claude 订阅的用量限额——5 小时会话、每周限额和模型每周限额，并分别显示距离重置的剩余时间。它始终显示在其他窗口之上，你无需打开“设置 → 使用情况”，也无需终端，就能随时查看 Claude 用量。

一个应用，同时支持 Windows 和 Mac。它涵盖所有计入你套餐的用量——claude.ai、Claude Desktop 和 Claude Code，覆盖你的所有设备。它不是终端工具“Claude Code Usage Monitor”：本应用是带托盘图标的图形化面板，不需要命令行。

关键术语，准确定义
5 小时会话（5 小时窗口）
Claude 的短期用量限额。基于会话的限额每五小时重置一次。Anthropic 称之为“当前会话”；很多用户称其为 5 小时窗口或 5 小时限制。
每周限额（周限额）
Claude 付费套餐的第二道上限，适用于所有模型，在分配给你账户的每周固定时间重置。每周限额自 2025 年 8 月 28 日起生效。
模型每周限额
针对某一个特定模型的单独每周上限，在 Claude 的用量页面上与其他所有模型的限额并列显示。小组件会把你所选模型的这项限额显示为第三个仪表。
重置
限额回到 0% 的时刻。小组件会倒计时到这一刻。通过 claude.ai 登录时，精确时间来自 Anthropic 的服务器；使用本地日志时则为估算值。
进度（pace）
与均匀使用一周相比，你超前或落后了多少。“较进度 +12%”表示你已用掉的每周限额，比本周已过去的时间比例多出 12 个百分点。
消耗速率
限额此刻被消耗的速度——会话按每小时百分比计算，每周限额按每天百分比计算——以及照此速度何时会达到 100%。
用量额度（extra usage）
达到套餐限额后可选的按量付费用量，可设置每月支出上限。小组件会显示它是否已开启、上限是多少，以及你已花费多少。

FAQ

Claude 用量限额常见问题，简短解答。

真的免费吗？有什么套路？

真的免费，没有任何套路。它不是演示版、不是试用版，也不是阉割版——这就是完整且唯一的版本。没有广告，没有付费版本，不收集数据。源代码以 MIT 许可证公开。

不打开设置，怎样查看我的 Claude 用量？

安装 Claude Usage Monitor：它以一个始终置顶的小组件，以及托盘或菜单栏中的百分比，把你的 5 小时会话、每周限额和模型限额一直显示在屏幕上。Claude 自己的数据在“设置 → 使用情况”中；小组件无需任何点击就能显示同样的限额。

Claude 的 5 小时会话和每周限额什么时候重置？

基于会话的限额每五小时重置一次。每周限额在 Anthropic 为你的账户分配的每周固定时间重置，因此每个人都不一样。小组件会实时倒计时到这两次重置——通过 claude.ai 登录时，使用的是来自 Anthropic 服务器的精确时间。

Claude Code 的用量会计入我的 claude.ai 限额吗？

会。根据 Anthropic 的说明，claude.ai、Claude Desktop 和 Claude Code 中的用量都计入同一个用量限额。因此，小组件的 claude.ai 模式显示的是你所有设备和应用的一个总数，而不只是它所运行的那台电脑。

它和“Claude Code Usage Monitor”是同一个东西吗？

不是。“Claude Code Usage Monitor”是另一位作者开发的独立终端工具。Vidovics Gábor 开发的 Claude Usage Monitor 是适用于 Windows 和 macOS 的图形化桌面小组件，带托盘图标、主题和提醒，不需要命令行。

怎样给 Claude Usage Monitor 评分或发送反馈？

右键点击面板并选择“给开发者留言…”，或点击面板标题栏中的留言图标。你可以打一到五颗星、写一段留言，并且——只有在你勾选的情况下——允许你的评分和姓名显示在本网站上。每一条留言都由作者 Vidovics Gábor 亲自阅读，未经你的同意，任何内容都不会公开。如果没有安装应用，请使用本页底部的表单。

Claude Usage Monitor 支持哪些语言？

支持 34 种语言：欧盟所有官方语言，外加日语、韩语、简体中文、繁体中文、印度尼西亚语和越南语——葡萄牙语分为欧洲版和巴西版，西班牙语分为西班牙版和拉丁美洲版。应用会自动选择你的系统语言，本网站也提供所有这些语言的版本。

它支持 Claude Pro、Max、Team 和 Enterprise 吗？

支持。它显示你自己的 Claude 套餐所具有的限额——Pro、Max 5×、Max 20×、Team 或 Enterprise——与 Claude 在“设置 → 使用情况”中列出的完全相同；面板标题栏中的套餐徽章会告诉你当前使用的是哪个套餐。

Claude Usage Monitor 能显示我的 Claude 文件是否已备份吗？

能——而且同样免费。开启备份状态栏后，面板上的三盏指示灯会显示备份到 OneDrive、备份到第二个云盘（如 Nextcloud）以及 Obsidian 仓库的备份是否最新：24 小时内为绿色，48 小时内为黄色，更早或缺失为红色，最近一次运行失败时显示红色圆环。本程序只读取备份日志；备份本身由免费的 Claude Backup Kit 完成，它每天复制你的 Claude Code 技能、CLAUDE.md、项目记忆、Claude Desktop 设置和智能体日志——绝不复制登录令牌。该工具包是任何人都可以修改的免费起点，因此我们对备份不承担任何责任：确保备份完整且可以恢复，是每位用户自己的责任。

这是 Anthropic 的官方产品吗？

不是。这是由 Vidovics Gábor 开发的独立社区工具，与 Anthropic 没有任何关联。“Claude”是 Anthropic, PBC 的商标。

我需要把密码告诉它吗？

绝对不需要。不登录时，它读取 Claude Desktop 的本地日志。如果想查看所有设备，你需要在自己的浏览器中登录 claude.ai——应用永远看不到你的密码。

因为本应用没有代码签名（证书要花钱，而应用是免费的）。点击“更多信息”→“仍要运行”即可。你可以用 SHA-256 校验和验证下载文件，也可以在 GitHub 上阅读源代码。

macOS 12 或更高版本。上方的下载卡片始终会显示当前版本适用的处理器。macOS 版刚刚推出——非常欢迎反馈。

更新是怎样进行的？

应用每天会向本网站检查几次。有新版本时会通知你；一键即可下载、校验并安装，然后自动重启。你也可以关闭此功能。
