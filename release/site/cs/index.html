Víc než čtečka místních protokolů

Limit ti ujídá i telefon. Teď to vidíš – přímo na ploše.

Spousta nástrojů na sledování využití čte soubory protokolů ve tvém počítači, takže ví jen to, kolik využil tenhle jeden počítač. Claude Usage Monitor se místo toho umí zeptat serveru Anthropic – a ukáže skutečné číslo za celý účet: počítá se všechno, co využiješ v aplikaci v telefonu, v prohlížeči, na jiném počítači i v Claude Code, a ty to vidíš na jednom místě – na své ploše.

Co je Claude Usage Monitor?

Claude Usage Monitor je bezplatný open-source widget na plochu pro Windows 10/11 a macOS, který v reálném čase ukazuje limity využití tvého předplatného Claude – 5hodinovou relaci, týdenní limit a týdenní limit modelu, u každého i čas zbývající do resetu. Drží se nad ostatními okny, takže využití Claude zkontroluješ, aniž bys otevíral „Settings → Usage“ (Nastavení → Využití), a bez terminálu.

Jedna aplikace pro Windows i Mac. Pokrývá všechno, co se počítá do tvého tarifu – claude.ai, Claude Desktop a Claude Code, na všech tvých zařízeních. Není to terminálový nástroj „Claude Code Usage Monitor“: tohle je grafický panel s ikonou v oznamovací oblasti a příkazový řádek nepotřebuje.

Klíčové pojmy, přesně definované
5hodinová relace (5hodinové okno, 5hodinový limit)
Krátkodobý limit využití Claude. Limit využití vázaný na relaci se resetuje každých pět hodin. Anthropic mu říká „five-hour session“ (pětihodinová relace) a v „Settings → Usage“ ho zobrazuje jako „Current session“ (aktuální relace); mnoho uživatelů mu říká 5hodinové okno nebo 5hodinový limit.
Týdenní limit
Druhý limit využití u placených tarifů Claude. Platí napříč všemi modely a resetuje se každý týden v pevný čas, který je přiřazený tvému účtu. Týdenní limity platí od 28. srpna 2025.
Týdenní limit modelu
Samostatný týdenní limit pro jeden konkrétní model. Na stránce „Usage“ (Využití) v nastavení Claude je uvedený vedle limitu pro všechny ostatní modely. Widget ho ukazuje jako třetí ukazatel pro model, který si zvolíš.
Reset (vynulování limitu)
Okamžik, kdy se limit vrátí na 0 %. Widget k němu odpočítává čas. Při přihlášení přes claude.ai přichází přesný čas ze serveru Anthropic; u místního protokolu jde o odhad.
Tempo
O kolik jsi napřed nebo pozadu oproti rovnoměrně využitému týdnu. „+12 % oproti tempu“ znamená, že jsi z týdenního limitu využil o 12 procentních bodů víc, než kolik činí podíl týdne, který už uplynul.
Rychlost čerpání (burn rate)
Jak rychle se limit plní právě teď – v procentech za hodinu u 5hodinové relace, v procentech za den u týdne – a kdy by při této rychlosti dosáhl 100 %.
Kredity za využití (extra využití, extra usage)
Volitelné kredity placené podle skutečného využití (pay-as-you-go) poté, co vyčerpáš limity využití svého tarifu, s měsíčním stropem útraty. Widget ukazuje, jestli jsou zapnuté, jaký je strop a kolik jsi už utratil.

Co získáš

Všechny tvoje limity využití Claude. Jediným pohledem.

Vidíš to přicházet

Zelená, žlutá, červená. Panel mění barvu dlouho předtím, než ti limit dojde – s odpočtem do resetu a odhadem, kdy bys narazil na 100 %.

Nečerpáš moc rychle?

Ukazatel tempa ti řekne, jestli tvůj týdenní limit taje rychleji, než utíká týden – a spočítá, kde nakonec skončíš.

Všechna zařízení, jedno číslo

Přihlas se ve vlastním prohlížeči – stejně jako to dělá Claude Code – a uvidíš i využití z telefonu, prohlížeče a všech ostatních počítačů.

Limity podle modelů

Fable, Opus, Sonnet, Claude Code, kredity za využití – každý limit, který server hlásí, plus rozdělení tohoto týdne mezi modely.

Jen upozornění, na kterých záleží

Tiché oznámení při 70 % a 90 % (hranice si zvolíš) a ve chvíli, kdy se limit resetuje. Nic dalšího. Nikdy.

Celý týden v jednom grafu

Dvojklik na widget: oba limity na jedné časové ose – 6 hodin, 24 hodin nebo 7 dní – s týdenním maximem, denním průměrem a odhadem na konec týdne, který změní barvu dřív, než limit překročíš.

Co je nového ve verzi 2.6.0

Poznámky k vydání se píšou anglicky a maďarsky.

  • New: the program now also runs on macOS. Everything system-specific has a macOS counterpart - sign-in token in the Keychain, start at login through a LaunchAgent, settings under ~/Library/Application Support, self-update of the .app bundle - while the Windows version behaves exactly as before.
  • The macOS build has its own release manifest, so the Windows and the macOS releases are published independently and never overwrite each other. An Apple Silicon build is never offered to an Intel Mac.
  • For developers: macos/build.sh builds the app with one command, macos/release.sh packages, uploads and verifies it, macos/doctor.sh collects diagnostics. The Windows release stays the base: a macOS release is only made for a version that is already out for Windows.
  • A stale single-instance lock left behind by a crash no longer blocks the next start on macOS/Linux.

FAQ

Otázky k limitům využití Claude – krátké odpovědi.

Je to opravdu zdarma? Kde je háček?

Opravdu zdarma a žádný háček v tom není. Není to demo, zkušební verze ani ořezaná edice – je to plná a jediná verze. Žádné reklamy, žádný placený tarif, žádný sběr dat. Zdrojový kód je veřejný pod licencí MIT.

Jak zjistím využití Claude, aniž bych otevíral nastavení?

Nainstaluj si Claude Usage Monitor: 5hodinovou relaci, týdenní limit a týdenní limit modelu ti drží pořád na obrazovce – jako malý widget vždy navrchu a jako procento v oznamovací oblasti nebo v řádku nabídek. Vlastní čísla Claude najdeš v „Settings → Usage“ (Nastavení → Využití); widget ukazuje stejné limity bez jediného kliknutí.

Kdy se resetuje 5hodinová relace Claude a kdy týdenní limit?

Limit využití vázaný na relaci se resetuje každých pět hodin. Týdenní limit se resetuje každý týden v pevný čas, který tvému účtu přiřadí Anthropic, takže ho má každý jinak. Widget živě odpočítává čas do obou resetů – při přihlášení přes claude.ai používá přesné časy ze serveru Anthropic.

Počítá se využití Claude Code do limitu na claude.ai?

Ano. Podle Anthropic se využití na claude.ai, v Claude Desktop a v Claude Code počítá do stejného limitu využití. Proto widget v režimu claude.ai ukazuje jedno číslo pro všechna tvoje zařízení a aplikace, ne jen pro počítač, na kterém běží.

Je to totéž co „Claude Code Usage Monitor“?

Ne. „Claude Code Usage Monitor“ je samostatný terminálový nástroj jiného autora. Claude Usage Monitor od Gábora Vidovicse je grafický widget na plochu pro Windows a macOS s ikonou v oznamovací oblasti, motivy a upozorněními a příkazový řádek nepotřebuje.

Je to oficiální produkt Anthropic?

Ne. Je to nezávislý komunitní nástroj, který vytvořil Gábor Vidovics. S Anthropic není nijak spojen. „Claude“ je ochranná známka společnosti Anthropic, PBC.

Musím aplikaci dát svoje heslo?

Nikdy. Bez přihlášení čte místní protokol Claude Desktop. Pokud chceš vidět všechna zařízení, přihlásíš se na claude.ai ve vlastním prohlížeči – aplikace tvoje heslo nikdy neuvidí.

Windows mě při spuštění varuje. Proč?

Protože aplikace není digitálně podepsaná (certifikáty stojí peníze a aplikace je zdarma). Klikni na Další informace → Přesto spustit. Stažený soubor si můžeš ověřit kontrolním součtem SHA-256 a zdrojový kód si přečíst na GitHubu.

macOS 12 nebo novější. Karta pro stažení výše vždy ukazuje, pro jaký procesor je aktuální sestavení určené. Verze pro macOS je nová – zpětná vazba je moc vítaná.

Jak ji odstraním?

Windows: Nastavení → Aplikace → Nainstalované aplikace → Claude Usage Monitor → Odinstalovat. macOS: přetáhni aplikaci do Koše. To je všechno.
