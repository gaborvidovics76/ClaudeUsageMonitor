O que é o Claude Usage Monitor?

O Claude Usage Monitor é um widget de desktop gratuito e de código aberto para Windows 10/11 e macOS que mostra em tempo real os limites de uso da sua assinatura do Claude – a sessão de cinco horas, o limite semanal e o limite semanal por modelo, cada um com o tempo que falta até o reset. Ele fica por cima das outras janelas, então você confere seu uso do Claude sem abrir Configurações → Uso e sem terminal.

Um só app para Windows e Mac. Ele cobre tudo o que conta para o seu plano – claude.ai, Claude Desktop e Claude Code, em todos os seus dispositivos. Não é a ferramenta de terminal “Claude Code Usage Monitor”: este é um painel gráfico com ícone na bandeja do sistema, e não precisa de linha de comando.

Termos-chave, definidos com precisão
Sessão de cinco horas (janela de 5 horas)
O limite de uso de curto prazo do Claude. Seu limite por sessão é redefinido a cada cinco horas. A Anthropic chama de “Sessão atual”; muitos usuários chamam de janela de 5 horas ou limite de 5 horas.
Limite semanal
Um segundo teto nos planos pagos do Claude, que vale para todos os modelos e é redefinido toda semana em um horário fixo, atribuído à sua conta. Os limites semanais estão em vigor desde 28 de agosto de 2025.
Limite semanal por modelo
Um teto semanal separado para um modelo específico, listado na página de uso do Claude ao lado do limite de todos os outros modelos. O widget mostra esse limite como um terceiro medidor para o modelo que você escolher.
Reset (redefinição)
O momento em que um limite volta a 0%. O widget faz a contagem regressiva até lá. Com login no claude.ai, o horário exato vem do servidor da Anthropic; com o log local, é uma estimativa.
Ritmo
O quanto você está adiantado ou atrasado em relação a uma semana de uso uniforme. “+12% acima do ritmo” significa que você usou 12 pontos percentuais a mais do seu limite semanal do que a parte da semana que já passou.
Taxa de consumo (burn rate)
A velocidade com que um limite está enchendo agora – porcentagem por hora na sessão, porcentagem por dia na semana – e quando ele chegaria a 100% nessa velocidade.
Créditos de uso (uso extra)
Uso opcional, pago conforme o consumo, depois que você atinge os limites do seu plano, com um teto mensal de gastos. O widget mostra se está ativado, o teto e quanto você já gastou.

Novidades da versão 2.6.0

As notas de versão são escritas em inglês e em húngaro.

  • New: the program now also runs on macOS. Everything system-specific has a macOS counterpart - sign-in token in the Keychain, start at login through a LaunchAgent, settings under ~/Library/Application Support, self-update of the .app bundle - while the Windows version behaves exactly as before.
  • The macOS build has its own release manifest, so the Windows and the macOS releases are published independently and never overwrite each other. An Apple Silicon build is never offered to an Intel Mac.
  • For developers: macos/build.sh builds the app with one command, macos/release.sh packages, uploads and verifies it, macos/doctor.sh collects diagnostics. The Windows release stays the base: a macOS release is only made for a version that is already out for Windows.
  • A stale single-instance lock left behind by a crash no longer blocks the next start on macOS/Linux.

FAQ

Perguntas sobre os limites de uso do Claude – respostas curtas.

É grátis mesmo? Qual é a pegadinha?

Grátis mesmo, e não tem pegadinha. Não é demo, não é versão de teste nem edição reduzida – esta é a versão completa e a única. Sem anúncios, sem plano pago, sem coleta de dados. O código-fonte é público sob a licença MIT.

Como ver meu uso do Claude sem abrir as Configurações?

Instale o Claude Usage Monitor: ele mantém na tela o tempo todo a sua sessão de cinco horas, o limite semanal e o limite por modelo, como um pequeno widget sempre visível e como uma porcentagem na bandeja do sistema ou na barra de menus. Os números do próprio Claude ficam em Configurações → Uso (em inglês, “Settings → Usage”); o widget mostra os mesmos limites sem nenhum clique.

Quando reseta a sessão de 5 horas e o limite semanal do Claude?

O limite por sessão é redefinido a cada cinco horas. O limite semanal é redefinido toda semana em um horário fixo que a Anthropic atribui à sua conta, então ele muda de pessoa para pessoa. O widget mostra uma contagem regressiva ao vivo até os dois resets – com login no claude.ai, ele usa os horários exatos do servidor da Anthropic.

O uso do Claude Code conta para o meu limite do claude.ai?

Sim. Segundo a Anthropic, o uso no claude.ai, no Claude Desktop e no Claude Code conta para o mesmo limite de uso. Por isso o modo claude.ai do widget mostra um só número para todos os seus dispositivos e apps, não só para o computador em que ele está instalado.

É a mesma coisa que o “Claude Code Usage Monitor”?

Não. O “Claude Code Usage Monitor” é outra ferramenta, de terminal e de outro autor. O Claude Usage Monitor, de Gábor Vidovics, é um widget gráfico de desktop para Windows e macOS com ícone na bandeja do sistema, temas e alertas, e não precisa de linha de comando.

É um produto oficial da Anthropic?

Não. É uma ferramenta independente da comunidade, criada por Gábor Vidovics. Não tem vínculo com a Anthropic. “Claude” é uma marca registrada da Anthropic, PBC.

Preciso informar a minha senha?

Nunca. Sem login, ele lê o log local do Claude Desktop. Se quiser ver todos os dispositivos, você entra no claude.ai pelo seu próprio navegador – o app nunca vê a sua senha.

O Windows mostra um aviso quando executo o app. Por quê?

Porque o app não tem assinatura de código (certificados custam dinheiro; o app é grátis). Clique em Mais informações → Executar assim mesmo. Você pode verificar o download pela soma de verificação SHA-256 e ler o código no GitHub.

Quais Macs são compatíveis?

macOS 12 ou mais recente. O cartão de download acima mostra sempre para qual processador é a versão atual. A versão para macOS é nova – seu feedback é muito bem-vindo.

Como funcionam as atualizações?

O app consulta este site algumas vezes por dia. Quando há uma versão nova, ele avisa; com um clique, baixa, verifica, instala e reinicia. Dá para desativar.

Como faço para remover?

Windows: Configurações → Aplicativos → Aplicativos instalados → Claude Usage Monitor → Desinstalar. macOS: arraste o app para o Lixo. Só isso.
