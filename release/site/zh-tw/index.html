連你的備份都看得到。知識如果可能毀於一旦，還值多少？

每個用量追蹤工具都只停在數字上。Claude Usage Monitor 多走了一步：它也會告訴你與 Claude 相關的備份是否夠新，包括你的技能、CLAUDE.md 規則、專案記憶、MCP 設定、代理程式對話記錄和 Obsidian 筆記。這些資料通常只存在一顆硬碟上。硬碟故障、筆電被偷、一次誤刪，幾個月的心血就沒了。面板上的三顆小燈號，一天中的每一分鐘都在告訴你：這種事不會發生在你身上。

三顆燈號，看一眼就知道。

  • 綠燈：最近一次成功的備份不超過 24 小時。
  • 黃燈：已經過了 24 到 48 小時，該看一下了。
  • 紅燈：超過 48 小時，或根本沒有備份。
  • 紅圈：最近一次執行失敗或沒有完成；即使較舊的備份仍讓燈號維持綠色，也會顯示紅圈。

三顆燈號分別是 OneDrive（第一份副本）、Nextcloud（第二個獨立的雲端，rclone 支援的任何雲端都可以）和 Obsidian（儲存庫的日期快照）。只有真正完成的執行才算數：失敗、中斷或試執行，絕不會讓燈號變綠。時數可以調整。按一下任一燈號即可檢視詳細資料。

10 分鐘完成設定：逐步說明
  1. 你需要準備：Windows 10 或 11、已登入 OneDrive、已安裝 Claude Usage Monitor。第二份副本需要 Nextcloud 帳號，或 rclone 支援的任何其他雲端（Google Drive、Dropbox、S3、pCloud、SFTP…）。沒有第二個雲端？步驟 2 可以略過。
  2. 建立應用程式密碼（僅第二個雲端需要）。在 Nextcloud 中：你的頭像 → 個人設定 → 安全性 → 裝置與工作階段 → 應用程式名稱填 rclone-backup → 建立新的應用程式密碼。請把它複製下來，它只會顯示一次。這不是你的帳號密碼，而且隨時都能撤銷。
  3. 下載並解壓縮 Backup Kit 到一個固定的資料夾，例如 C:\Tools\ClaudeBackup。
  4. 用記事本編輯 config.psd1：VaultPath = 你的 Obsidian 儲存庫（留空 = 不使用 Obsidian），ExtraFolders = 其他要備份的項目，NextcloudRemote 和 NextcloudBasePath = 第二個雲端（留空 = 略過），DailyTime = 執行時間。其他設定都可以維持原樣。
  5. 以系統管理員身分執行安裝程式：Win+X → 終端機 (系統管理員)，然後依序輸入 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned、cd C:\Tools\ClaudeBackup、Unblock-File *.ps1、.\Install-BackupKit.ps1。它會視需要安裝 rclone，詢問雲端位址、使用者名稱和應用程式密碼（輸入時不會顯示），建立兩個排程工作，告訴監控程式要去哪裡讀取，並執行第一次備份。
  6. 第一次正式上傳：.\Backup-Step2-Cloud.ps1：安裝程式只對步驟 2 做了試執行。
  7. 檢查：.\Test-BackupKit.ps1：每一行都應該顯示 [OK]。在 Claude Usage Monitor 中：在面板上按右鍵 → 備份狀態列。三顆燈號會在 5 分鐘內變綠，或在 備份… → 立即檢查 後馬上變綠。

安全性：套件如何保護你的資料
  • 套件的任何檔案中都沒有密碼。應用程式密碼在輸入時不會顯示，而且只以混淆形式存放在 rclone 自己的設定中。你隨時可以在 Nextcloud 中撤銷它。
  • 絕不複製登入權杖。Claude Desktop 的 Cookie 也不會複製。
  • 不做鏡像同步。你在電腦上刪除的檔案，仍會保留在兩份備份中；鏡像同步會連錯誤也原封不動地複製過去。
  • 帶日期的儲存庫快照，因此即使之後複製到有問題的版本，也絕不會覆蓋先前完好的狀態。
  • 兩個獨立的服務供應商。就算其中一個故障或把你鎖在門外，另一個仍保有全部資料。
  • 值得注意：Claude Desktop 的設定檔和 .claude\settings.json 可能包含 MCP 伺服器的 API 金鑰。這些檔案會被備份（還原時需要它們），存到你自己的 OneDrive 和你自己的雲端。請為這兩個帳號都啟用兩步驟驗證。

Claude Usage Monitor 是什麼？

Claude Usage Monitor 是一款免費、開放原始碼的桌面小工具，適用於 Windows 10/11 與 macOS，能即時顯示你 Claude 訂閱方案的使用上限：5 小時工作階段、每週上限，以及各模型每週上限，每一項都附有距離重設的剩餘時間。它會停留在其他視窗之上，讓你不必開啟「設定 → 使用」、也不必打開終端機，就能查看 Claude 用量。

同一個程式，Windows 和 Mac 都能用。所有計入你方案的使用量它都涵蓋：claude.ai、Claude Desktop 與 Claude Code，橫跨你所有的裝置。它不是終端機工具「Claude Code Usage Monitor」：這是一個附系統匣圖示的圖形化面板，完全不需要命令列。

重要名詞，精確定義
5 小時工作階段（5 小時限制）
Claude 的短期使用上限。以工作階段計算的上限每五小時重設一次。Anthropic 稱之為「目前工作階段」；許多使用者則稱為 5 小時限制或 5 小時額度。
每週上限
付費 Claude 方案的第二道上限，適用於所有模型，並在指派給你帳戶的每週固定時間重設。每週上限自 2025 年 8 月 28 日起實施。
各模型每週上限
針對某個特定模型的獨立每週上限，列在 Claude 的使用量頁面上，就在「所有其他模型」的上限旁邊。小工具會把你選擇的模型顯示為第三個儀表。
重設
上限回到 0% 的那一刻。小工具會倒數計時到這一刻。透過 claude.ai 登入時，精確時間來自 Anthropic 的伺服器；使用本機記錄檔時則是估計值。
步調
和平均分配的一週相比，你超前或落後多少。「較步調 +12%」表示你用掉的每週上限，比本週已經過去的比例多了 12 個百分點。
消耗速率
目前用掉上限的速度：工作階段以每小時百分比計算，每週以每天百分比計算，並推算照這個速度何時會到達 100%。
使用額度（額外用量）
達到方案上限後可選用的隨用隨付用量，並設有每月支出上限。小工具會顯示它是否已開啟、上限金額，以及你已花費的金額。

FAQ

Claude 使用上限常見問題，簡短回答。

真的免費嗎？有什麼陷阱？

真的免費，也沒有任何陷阱。它不是展示版、不是試用版，也不是精簡版，這就是完整且唯一的版本。沒有廣告、沒有付費版、不蒐集資料。原始碼以 MIT 授權公開。

不打開設定，要怎麼查看 Claude 用量？

安裝 Claude Usage Monitor：它會以永遠置頂的小工具，以及系統匣或選單列中的百分比，隨時把你的 5 小時工作階段、每週上限和各模型上限顯示在螢幕上。Claude 本身的數字在「設定 → 使用」中；小工具則不必點任何地方，就能顯示同樣的上限。

Claude 的 5 小時工作階段和每週上限什麼時候重設？

以工作階段計算的上限每五小時重設一次。每週上限則在 Anthropic 指派給你帳戶的每週固定時間重設，因此每個人都不一樣。小工具會即時倒數這兩種重設；透過 claude.ai 登入時，使用的是 Anthropic 伺服器提供的精確時間。

Claude Code 的用量會算進 claude.ai 的上限嗎？

會。根據 Anthropic 的說明，claude.ai、Claude Desktop 和 Claude Code 的使用量都計入同一個使用上限。所以小工具的 claude.ai 模式會為你所有的裝置和應用程式顯示同一個數字，而不只是執行它的那台電腦。

這和「Claude Code Usage Monitor」是同一個東西嗎？

不是。「Claude Code Usage Monitor」是另一位作者開發、在終端機中執行的獨立工具。Vidovics Gábor 開發的 Claude Usage Monitor 則是適用於 Windows 和 macOS 的圖形化桌面小工具，有系統匣圖示、佈景主題和警示，完全不需要命令列。

要怎麼為 Claude Usage Monitor 評分或提供意見回饋？

在面板上按右鍵並選擇「傳訊息給開發者…」，或按一下面板標題列中的訊息圖示。你可以給一到五顆星、寫下訊息，而且只有在你勾選時，才會允許在本網站上顯示你的評分和姓名。每一則訊息都由作者 Vidovics Gábor 親自閱讀，未經你同意，任何內容都不會公開。如果沒有安裝程式，請使用本頁底部的表單。

Claude Usage Monitor 支援哪些語言？

共 34 種語言：歐盟所有官方語言，再加上日文、韓文、簡體中文、繁體中文、印尼文和越南文；葡萄牙文分為歐洲版與巴西版，西班牙文也分為西班牙版與拉丁美洲版。程式會自動選用你的系統語言，本網站也提供上述每一種語言的版本。

支援 Claude Pro、Max、Team 和 Enterprise 嗎？

支援。它會顯示你自己的 Claude 方案所擁有的上限（Pro、Max 5×、Max 20×、Team 或 Enterprise），也就是 Claude 在「設定 → 使用」中列出的那些；面板標題列中的方案標章會告訴你目前使用的是哪個方案。

Claude Usage Monitor 能顯示我的 Claude 檔案是否已備份嗎？

可以，而且同樣免費。開啟備份狀態列後，面板上的三顆燈號會顯示 OneDrive 備份、第二個雲端（例如 Nextcloud）備份以及 Obsidian 儲存庫備份是否夠新：24 小時內為綠燈，48 小時內為黃燈，更舊或沒有備份時為紅燈，最近一次執行失敗時則顯示紅圈。監控程式只會讀取備份記錄檔；備份本身由免費的 Claude Backup Kit 製作，它每天複製你的 Claude Code 技能、CLAUDE.md、專案記憶、Claude Desktop 設定和代理程式記錄，但絕不複製登入權杖。這個套件是任何人都能修改的免費起點，因此我們對備份概不負責：確保備份完整且可還原，是每位使用者自己的責任。
