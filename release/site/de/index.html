Auch dein Handy frisst dein Limit. Jetzt siehst du es – auf deinem Desktop.

Was ist Claude Usage Monitor?

Claude Usage Monitor ist ein kostenloses Open-Source-Desktop-Widget für Windows 10/11 und macOS, das dir die Nutzungslimits deines Claude-Abos in Echtzeit zeigt – die 5-Stunden-Sitzung, das Wochenlimit und das Wochenlimit pro Modell, jeweils mit der verbleibenden Zeit bis zum Reset. Es bleibt über deinen anderen Fenstern im Vordergrund. So siehst du deine Claude-Nutzung, ohne „Einstellungen → Nutzung“ zu öffnen und ohne Terminal.

Eine App für Windows und Mac. Sie erfasst alles, was auf deinen Plan angerechnet wird – claude.ai, Claude Desktop und Claude Code, auf allen deinen Geräten. Sie ist nicht das Terminal-Tool „Claude Code Usage Monitor“: Das hier ist ein grafisches Panel mit Tray-Symbol und braucht keine Kommandozeile.

Wichtige Begriffe, genau erklärt
5-Stunden-Sitzung (5-Stunden-Fenster)
Das kurzfristige Nutzungslimit von Claude. Dein sitzungsbasiertes Limit wird alle fünf Stunden zurückgesetzt. Anthropic nennt es „Aktuelle Sitzung“ (englisch „current session“); viele Nutzer sagen 5-Stunden-Fenster oder 5-Stunden-Limit.
Wochenlimit (wöchentliches Nutzungslimit)
Eine zweite Obergrenze in den bezahlten Claude-Plänen. Sie gilt für alle Modelle zusammen und wird jede Woche zu einem festen Zeitpunkt zurückgesetzt, der deinem Konto zugewiesen ist. Wochenlimits gelten seit dem 28. August 2025.
Wochenlimit pro Modell
Eine eigene wöchentliche Obergrenze für ein bestimmtes Modell. Auf der Nutzungsseite von Claude steht sie neben dem Limit für alle anderen Modelle. Das Widget zeigt sie als dritte Anzeige für das Modell deiner Wahl.
Reset (Zurücksetzung)
Der Moment, in dem ein Limit wieder auf 0% springt. Das Widget zählt bis dahin herunter. Mit claude.ai-Anmeldung kommt die exakte Zeit vom Anthropic-Server; beim lokalen Protokoll ist sie eine Schätzung.
Tempo (Pace)
Wie weit du vor oder hinter einer gleichmäßig genutzten Woche liegst. „+12% vs pace“ (12% über dem Tempo) bedeutet: Du hast 12 Prozentpunkte mehr von deinem Wochenlimit verbraucht, als der bereits vergangene Anteil der Woche ausmacht.
Verbrauchsrate (Burn Rate)
Wie schnell sich ein Limit gerade füllt – Prozent pro Stunde bei der Sitzung, Prozent pro Tag bei der Woche – und wann es bei dieser Geschwindigkeit 100% erreichen würde.
Nutzungsguthaben (Zusatznutzung)
Optionale, nach Verbrauch abgerechnete Nutzung, nachdem du die Limits deines Plans erreicht hast – mit einer monatlichen Ausgabenobergrenze. Das Widget zeigt, ob sie eingeschaltet ist, wie hoch die Obergrenze ist und was du bisher ausgegeben hast.

Die Versionshinweise erscheinen auf Englisch und Ungarisch.

  • New: the program now also runs on macOS. Everything system-specific has a macOS counterpart - sign-in token in the Keychain, start at login through a LaunchAgent, settings under ~/Library/Application Support, self-update of the .app bundle - while the Windows version behaves exactly as before.
  • The macOS build has its own release manifest, so the Windows and the macOS releases are published independently and never overwrite each other. An Apple Silicon build is never offered to an Intel Mac.
  • For developers: macos/build.sh builds the app with one command, macos/release.sh packages, uploads and verifies it, macos/doctor.sh collects diagnostics. The Windows release stays the base: a macOS release is only made for a version that is already out for Windows.
  • A stale single-instance lock left behind by a crash no longer blocks the next start on macOS/Linux.

FAQ

Fragen zu den Claude-Nutzungslimits – kurze Antworten.

Ist es wirklich kostenlos? Wo ist der Haken?

Wirklich kostenlos, und es gibt keinen Haken. Keine Demo, keine Testversion und keine abgespeckte Ausgabe – das hier ist die vollständige und einzige Version. Keine Werbung, keine Bezahlstufe, keine Datensammlung. Der Quellcode ist unter der MIT-Lizenz öffentlich.

Wie kann ich meine Claude-Nutzung sehen, ohne die Einstellungen zu öffnen?

Installiere Claude Usage Monitor: Das Tool hält deine 5-Stunden-Sitzung, dein Wochenlimit und dein Wochenlimit pro Modell ständig auf dem Bildschirm – als kleines Widget, das immer im Vordergrund bleibt, und als Prozentwert im Infobereich oder in der Menüleiste. Claudes eigene Zahlen findest du unter „Einstellungen → Nutzung“; das Widget zeigt dieselben Limits ganz ohne Klicken.

Wann werden die 5-Stunden-Sitzung und das Wochenlimit bei Claude zurückgesetzt?

Das sitzungsbasierte Limit wird alle fünf Stunden zurückgesetzt. Das Wochenlimit wird jede Woche zu einem festen Zeitpunkt zurückgesetzt, den Anthropic deinem Konto zuweist – er ist also von Person zu Person verschieden. Das Widget zeigt einen Live-Countdown bis zu beiden Resets; mit claude.ai-Anmeldung nutzt es die exakten Zeiten vom Anthropic-Server.

Zählt die Nutzung von Claude Code zu meinem claude.ai-Limit?

Ja. Laut Anthropic wird die Nutzung von claude.ai, Claude Desktop und Claude Code auf dasselbe Nutzungslimit angerechnet. Deshalb zeigt das Widget im claude.ai-Modus eine Zahl für alle deine Geräte und Apps – nicht nur für den Computer, auf dem es läuft.

Ist das dasselbe wie „Claude Code Usage Monitor“?

Nein. „Claude Code Usage Monitor“ ist ein eigenes, terminalbasiertes Tool eines anderen Autors. Claude Usage Monitor von Gábor Vidovics ist ein grafisches Desktop-Widget für Windows und macOS mit Tray-Symbol, Themes und Hinweisen – und es braucht keine Kommandozeile.

Ist das ein offizielles Anthropic-Produkt?

Nein. Es ist ein unabhängiges Community-Tool von Gábor Vidovics. Es steht in keiner Verbindung zu Anthropic. „Claude“ ist eine Marke von Anthropic, PBC.

Muss ich der App mein Passwort geben?

Nie. Ohne Anmeldung liest sie das lokale Protokoll von Claude Desktop. Willst du alle Geräte sehen, meldest du dich in deinem eigenen Browser bei claude.ai an – die App bekommt dein Passwort nie zu sehen.

Windows warnt mich beim Start. Warum?

Weil die App nicht code-signiert ist (Zertifikate kosten Geld; die App ist kostenlos). Klick auf Weitere Informationen → Trotzdem ausführen. Du kannst den Download anhand seiner SHA-256-Prüfsumme kontrollieren und den Quellcode auf GitHub lesen.

Welche Macs werden unterstützt?

macOS 12 oder neuer. Die Download-Karte oben zeigt immer, für welchen Prozessor die aktuelle Version gebaut ist. Die macOS-Version ist neu – Feedback ist sehr willkommen.

Wie funktionieren die Updates?

Die App schaut ein paar Mal am Tag auf dieser Website nach. Gibt es eine neue Version, sagt sie dir Bescheid; ein Klick lädt sie herunter, prüft und installiert sie und startet die App neu. Das lässt sich abschalten.

Wie werde ich es wieder los?

Windows: Einstellungen → Apps → Installierte Apps → Claude Usage Monitor → Deinstallieren. macOS: Zieh die App in den Papierkorb. Das war's.
