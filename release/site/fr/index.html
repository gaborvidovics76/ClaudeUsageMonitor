Il affiche même vos sauvegardes. Que vaut le savoir s'il peut être détruit ?

Tous les outils de suivi d'utilisation s'arrêtent aux chiffres. Claude Usage Monitor va un pas plus loin : il indique aussi si vos sauvegardes liées à Claude sont à jour – vos skills, vos règles CLAUDE.md, la mémoire de projet, les paramètres MCP, les journaux de conversation des agents et vos notes Obsidian. Le plus souvent, tout cela se trouve sur un seul disque. Un disque en panne, un portable volé, une mauvaise suppression – et des mois de travail disparaissent. Trois petits voyants sur le panneau vous confirment, à chaque minute de la journée, que cela ne peut pas vous arriver.

Trois voyants. Un coup d'œil. Vous savez.

  • Vert – la dernière sauvegarde réussie date de 24 heures au plus.
  • Jaune – elle date de 24 à 48 heures. Il est temps de vérifier.
  • Rouge – plus de 48 heures, ou aucune sauvegarde du tout.
  • Anneau rouge – la dernière exécution a échoué ou ne s'est pas terminée, même si une sauvegarde plus ancienne maintient encore le voyant au vert.

Les voyants correspondent à OneDrive (première copie), Nextcloud (second cloud, indépendant – tout cloud pris en charge par rclone convient) et Obsidian (instantané daté de votre coffre). Seule compte une exécution réellement terminée : une exécution échouée, interrompue ou de test ne fait jamais passer un voyant au vert. Les seuils en heures sont réglables. Cliquez sur un voyant pour voir les détails.

Aide : mettre en place une sauvegarde que le moniteur peut afficher

N'ouvrez que ce dont vous avez besoin. Chaque étape est ici – quoi utiliser, quoi régler, où cliquer. Le kit est un point de départ que vous pouvez modifier – lisez la clause de non-responsabilité ci-dessus.

Prêt en 10 minutes – étape par étape
  1. Ce qu'il vous faut. Windows 10 ou 11, OneDrive connecté, Claude Usage Monitor installé. Pour la seconde copie : un compte Nextcloud – ou tout autre cloud pris en charge par rclone (Google Drive, Dropbox, S3, pCloud, SFTP…). Pas de second cloud ? L'étape 2 est facultative.
  2. Créez un mot de passe d'application (uniquement pour le second cloud). Dans Nextcloud : votre avatar → Paramètres personnels → Sécurité → Appareils & sessions → nom de l'application rclone-backup → Créer un nouveau mot de passe d'application. Copiez-le – il n'est affiché qu'une seule fois. Ce n'est pas le mot de passe de votre compte, et vous pouvez le révoquer à tout moment.
  3. Téléchargez et décompressez le Backup Kit dans un dossier permanent, par exemple C:\Tools\ClaudeBackup.
  4. Modifiez config.psd1 dans le Bloc-notes : VaultPath = votre coffre Obsidian (vide = pas d'Obsidian), ExtraFolders = tout ce que vous voulez sauvegarder en plus, NextcloudRemote et NextcloudBasePath = le second cloud (vide = ignoré), DailyTime = l'heure d'exécution. Tout le reste peut rester tel quel.
  5. Lancez l'installeur en tant qu'administrateur : Win+X → Terminal (administrateur), puis Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, cd C:\Tools\ClaudeBackup, Unblock-File *.ps1, .\Install-BackupKit.ps1. Il installe rclone si nécessaire, demande l'adresse du cloud, le nom d'utilisateur et le mot de passe d'application (saisie masquée), crée les deux tâches planifiées, indique au moniteur où regarder et effectue une première exécution.
  6. Premier vrai envoi :.\Backup-Step2-Cloud.ps1 – l'installeur n'a fait qu'une exécution de test de l'étape 2.
  7. Vérifiez :.\Test-BackupKit.ps1 – chaque ligne doit afficher [OK]. Dans Claude Usage Monitor : clic droit sur le panneau → Barre d'état des sauvegardes. Les trois voyants passent au vert en 5 minutes, ou immédiatement avec Sauvegardes… → Vérifier maintenant.
Ce qui est sauvegardé – et ce qui ne l'est jamais
  • Claude Code (%USERPROFILE%\.claude) – skills, paramètres, CLAUDE.md, mémoire de projet, plugins.
  • Claude Desktop (%APPDATA%\Claude) – paramètres et serveurs MCP.
  • Journaux de conversation des agents – un ZIP par session.
  • Coffre Obsidian – un instantané ZIP daté à chaque exécution, conservé 30 jours.
  • Vos dossiers supplémentaires – tout ce que vous indiquez dans config.psd1.
  • Jamais : le jeton de connexion de Claude Code (.credentials.json), les cookies et caches de Claude Desktop, ni les grosses images de VM retéléchargeables.

Sécurité – comment le kit protège vos données
  • Aucun mot de passe dans les fichiers du kit. Le mot de passe d'application est saisi de façon masquée et stocké uniquement, sous forme obscurcie, dans la configuration propre à rclone. Révoquez-le dans Nextcloud quand vous voulez.
  • Le jeton de connexion n'est jamais copié. Les cookies de Claude Desktop non plus.
  • Pas de miroir. Un fichier que vous supprimez sur votre ordinateur reste dans les deux sauvegardes – un miroir recopierait fidèlement une erreur aussi.
  • Des instantanés datés du coffre, pour qu'une copie défectueuse ultérieure ne puisse jamais écraser un état antérieur sain.
  • Deux fournisseurs indépendants. Si l'un tombe en panne ou bloque votre accès, l'autre a toujours tout.
  • Bon à savoir : la configuration de Claude Desktop et .claude\settings.json peuvent contenir des clés API de serveurs MCP. Elles sont sauvegardées – il vous les faut pour une restauration – dans votre propre OneDrive et votre propre cloud. Protégez ces deux comptes par la validation en deux étapes.

Claude Usage Monitor, c'est quoi ?

Claude Usage Monitor est un widget de bureau gratuit et open source pour Windows 10/11 et macOS qui affiche en temps réel les limites d'utilisation de votre abonnement Claude – la session de cinq heures, la limite hebdomadaire et la limite hebdomadaire par modèle, chacune avec le temps restant avant sa réinitialisation. Il reste au-dessus de vos autres fenêtres : vous vérifiez votre utilisation de Claude sans ouvrir Paramètres → Utilisation et sans terminal.

Une seule application pour Windows et pour Mac. Elle couvre tout ce qui compte dans votre abonnement – claude.ai, Claude Desktop et Claude Code, sur tous vos appareils. Ce n'est pas l'outil en terminal « Claude Code Usage Monitor » : celui-ci est un panneau graphique avec une icône dans la zone de notification, et il ne demande aucune ligne de commande.

Dernière mise à jour: 2026-09-21 · Version 2.6.3 · par Vidovics Gábor

Les termes clés, définis avec précision
Session de cinq heures (fenêtre de 5 heures, limite de 5 heures)
La limite d'utilisation à court terme de Claude. Anthropic parle de « limite d'utilisation basée sur la session » : elle se réinitialise toutes les cinq heures et apparaît sous « Session actuelle » dans Paramètres → Utilisation. Beaucoup d'utilisateurs disent fenêtre de 5 heures ou limite de 5 heures.
Limite hebdomadaire (quota hebdomadaire)
Une seconde limite d'utilisation des abonnements Claude payants. Elle s'applique à tous les modèles et se réinitialise chaque semaine à une heure fixe, attribuée à votre compte. Les limites hebdomadaires sont en vigueur depuis le 28 août 2025.
Limite hebdomadaire par modèle
Une limite hebdomadaire distincte pour un modèle précis, affichée sous « Limites hebdomadaires » dans Paramètres → Utilisation, à côté de la limite pour tous les autres modèles. Le widget l'affiche comme une troisième jauge, pour le modèle de votre choix.
Réinitialisation (reset)
Le moment où une limite revient à 0 %. Le widget affiche un compte à rebours jusqu'à ce moment. Avec la connexion claude.ai, l'heure exacte vient du serveur d'Anthropic ; avec le journal local, c'est une estimation.
Rythme
Votre avance ou votre retard par rapport à une semaine utilisée de façon régulière. « +12 % par rapport au rythme » signifie que vous avez utilisé 12 points de pourcentage de votre limite hebdomadaire de plus que la part de la semaine déjà écoulée.
Vitesse de consommation (burn rate)
La vitesse à laquelle une limite se remplit en ce moment – en pour cent par heure pour la session, en pour cent par jour pour la semaine – et le moment où elle atteindrait 100 % à cette vitesse.
Crédits d'utilisation (utilisation supplémentaire)
Une utilisation facultative, payée à la consommation, une fois les limites de votre abonnement atteintes, avec un plafond de dépenses mensuel. Le widget indique si elle est activée, le plafond et ce que vous avez dépensé.

FAQ

Questions sur les limites d'utilisation de Claude – réponses courtes.

C'est vraiment gratuit ? Où est le piège ?

Vraiment gratuit, et il n'y a pas de piège. Ce n'est ni une démo, ni une version d'essai, ni une édition bridée – c'est la version complète, et la seule. Pas de pub, pas d'offre payante, pas de collecte de données. Le code source est public, sous licence MIT.

Comment voir mon utilisation de Claude sans ouvrir les Paramètres ?

Installez Claude Usage Monitor : il garde en permanence à l'écran votre session de cinq heures, votre limite hebdomadaire et votre limite par modèle, sous la forme d'un petit widget toujours au premier plan et d'un pourcentage dans la zone de notification ou la barre des menus. Les chiffres de Claude se trouvent dans Paramètres → Utilisation ; le widget affiche les mêmes limites, sans aucun clic.

Quand la session de 5 heures et la limite hebdomadaire de Claude se réinitialisent-elles ?

La limite basée sur la session se réinitialise toutes les cinq heures. La limite hebdomadaire se réinitialise chaque semaine à une heure fixe qu'Anthropic attribue à votre compte ; elle varie donc d'une personne à l'autre. Le widget affiche un compte à rebours en direct jusqu'aux deux réinitialisations – avec la connexion claude.ai, il utilise les heures exactes du serveur d'Anthropic.

L'utilisation de Claude Code compte-t-elle dans ma limite claude.ai ?

Oui. Selon Anthropic, l'utilisation sur claude.ai, Claude Desktop et Claude Code compte dans la même limite d'utilisation. C'est pourquoi le mode claude.ai du widget affiche un seul chiffre pour tous vos appareils et toutes vos applications, et pas seulement pour l'ordinateur sur lequel il tourne.

Est-ce la même chose que « Claude Code Usage Monitor » ?

Non. « Claude Code Usage Monitor » est un outil distinct, en terminal, créé par un autre auteur. Claude Usage Monitor de Gábor Vidovics est un widget de bureau graphique pour Windows et macOS, avec une icône dans la zone de notification, des thèmes et des alertes, et il ne demande aucune ligne de commande.

Claude Usage Monitor peut-il montrer si mes fichiers Claude sont sauvegardés ?

Oui – et c'est gratuit, là aussi. Une fois la barre d'état des sauvegardes activée, trois voyants sur le panneau indiquent si la sauvegarde vers OneDrive, vers un second cloud comme Nextcloud et celle de votre coffre Obsidian est à jour : vert jusqu'à 24 heures, jaune jusqu'à 48, rouge si elle est plus ancienne ou absente, et un anneau rouge si la dernière exécution a échoué. Le moniteur se contente de lire les journaux de sauvegarde ; la sauvegarde elle-même est réalisée par le Claude Backup Kit gratuit, qui copie chaque jour vos skills Claude Code, CLAUDE.md, la mémoire de projet, les paramètres de Claude Desktop et les journaux des agents – jamais le jeton de connexion. Le kit est un point de départ gratuit que chacun peut modifier, c'est pourquoi nous déclinons toute responsabilité concernant les sauvegardes : il revient à chaque utilisateur de s'assurer qu'elles sont complètes et peuvent être restaurées.

Est-ce un produit officiel d'Anthropic ?

Non. C'est un outil communautaire indépendant créé par Gábor Vidovics. Il n'est pas affilié à Anthropic. « Claude » est une marque d'Anthropic, PBC.

Dois-je lui donner mon mot de passe ?

Jamais. Sans connexion, il lit le journal local de Claude Desktop. Si vous voulez tous vos appareils, vous vous connectez à claude.ai dans votre propre navigateur – l'application ne voit jamais votre mot de passe.

Windows m'avertit quand je le lance. Pourquoi ?

Parce que le code de l'application n'est pas signé (les certificats coûtent de l'argent ; l'application est gratuite). Cliquez sur Informations complémentaires → Exécuter quand même. Vous pouvez vérifier le téléchargement grâce à son empreinte SHA-256 et lire le code source sur GitHub.

Quels Mac sont pris en charge ?

macOS 12 ou version ultérieure. La carte de téléchargement ci-dessus indique toujours à quel processeur la version actuelle est destinée. La version macOS est toute récente – vos retours sont les bienvenus.

Comment fonctionnent les mises à jour ?

L'application consulte ce site quelques fois par jour. Quand une nouvelle version existe, elle vous prévient ; un clic suffit pour la télécharger, la vérifier et l'installer, puis l'application redémarre. Vous pouvez désactiver cette fonction.

Comment le désinstaller ?

Windows : Paramètres → Applications → Applications installées → Claude Usage Monitor → Désinstaller. macOS : glissez l'application dans la Corbeille. C'est tout.
