Claude Usage Monitor, c'est quoi ?

Claude Usage Monitor est un widget de bureau gratuit et open source pour Windows 10/11 et macOS qui affiche en temps réel les limites d'utilisation de votre abonnement Claude – la session de cinq heures, la limite hebdomadaire et la limite hebdomadaire par modèle, chacune avec le temps restant avant sa réinitialisation. Il reste au-dessus de vos autres fenêtres : vous vérifiez votre utilisation de Claude sans ouvrir Paramètres → Utilisation et sans terminal.

Une seule application pour Windows et pour Mac. Elle couvre tout ce qui compte dans votre abonnement – claude.ai, Claude Desktop et Claude Code, sur tous vos appareils. Ce n'est pas l'outil en terminal « Claude Code Usage Monitor » : celui-ci est un panneau graphique avec une icône dans la zone de notification, et il ne demande aucune ligne de commande.

Les termes clés, définis avec précision
Session de cinq heures (fenêtre de 5 heures)
La limite d'utilisation à court terme de Claude. Votre limite basée sur la session se réinitialise toutes les cinq heures. Anthropic l'appelle la « session en cours » ; beaucoup d'utilisateurs disent fenêtre de 5 heures ou limite de 5 heures.
Limite hebdomadaire
Un second plafond des abonnements Claude payants. Il s'applique à tous les modèles et se réinitialise chaque semaine à une heure fixe, attribuée à votre compte. Les limites hebdomadaires sont en vigueur depuis le 28 août 2025.
Limite hebdomadaire par modèle
Un plafond hebdomadaire distinct pour un modèle précis, affiché sur la page d'utilisation de Claude à côté de la limite pour tous les autres modèles. Le widget l'affiche comme une troisième jauge, pour le modèle de votre choix.
Réinitialisation (reset)
Le moment où une limite revient à 0 %. Le widget affiche un compte à rebours jusqu'à ce moment. Avec la connexion claude.ai, l'heure exacte vient du serveur d'Anthropic ; avec le journal local, c'est une estimation.
Rythme
Votre avance ou votre retard par rapport à une semaine utilisée de façon régulière. « +12 % par rapport au rythme » signifie que vous avez utilisé 12 points de pourcentage de votre limite hebdomadaire de plus que la part de la semaine déjà écoulée.
Vitesse de consommation (burn rate)
La vitesse à laquelle une limite se remplit en ce moment – en pour cent par heure pour la session, en pour cent par jour pour la semaine – et le moment où elle atteindrait 100 % à cette vitesse.
Crédits d'utilisation (utilisation supplémentaire)
Une utilisation facultative, payée à la consommation, une fois les limites de votre abonnement atteintes, avec un plafond de dépenses mensuel. Le widget indique si elle est activée, le plafond et ce que vous avez dépensé.

Nouveautés de la version 2.6.0

Les notes de version sont rédigées en anglais et en hongrois.

  • New: the program now also runs on macOS. Everything system-specific has a macOS counterpart - sign-in token in the Keychain, start at login through a LaunchAgent, settings under ~/Library/Application Support, self-update of the .app bundle - while the Windows version behaves exactly as before.
  • The macOS build has its own release manifest, so the Windows and the macOS releases are published independently and never overwrite each other. An Apple Silicon build is never offered to an Intel Mac.
  • For developers: macos/build.sh builds the app with one command, macos/release.sh packages, uploads and verifies it, macos/doctor.sh collects diagnostics. The Windows release stays the base: a macOS release is only made for a version that is already out for Windows.
  • A stale single-instance lock left behind by a crash no longer blocks the next start on macOS/Linux.

FAQ

Questions sur les limites d'utilisation de Claude – réponses courtes.

C'est vraiment gratuit ? Où est le piège ?

Vraiment gratuit, et il n'y a pas de piège. Ce n'est ni une démo, ni une version d'essai, ni une édition bridée – c'est la version complète, et la seule. Pas de pub, pas d'offre payante, pas de collecte de données. Le code source est public, sous licence MIT.

Comment voir mon utilisation de Claude sans ouvrir les Paramètres ?

Installez Claude Usage Monitor : il garde en permanence à l'écran votre session de cinq heures, votre limite hebdomadaire et votre limite par modèle, sous la forme d'un petit widget toujours au premier plan et d'un pourcentage dans la zone de notification ou la barre des menus. Les chiffres de Claude se trouvent dans Paramètres → Utilisation ; le widget affiche les mêmes limites, sans aucun clic.

Quand la session de 5 heures et la limite hebdomadaire de Claude se réinitialisent-elles ?

La limite basée sur la session se réinitialise toutes les cinq heures. La limite hebdomadaire se réinitialise chaque semaine à une heure fixe qu'Anthropic attribue à votre compte ; elle varie donc d'une personne à l'autre. Le widget affiche un compte à rebours en direct jusqu'aux deux réinitialisations – avec la connexion claude.ai, il utilise les heures exactes du serveur d'Anthropic.

L'utilisation de Claude Code compte-t-elle dans ma limite claude.ai ?

Oui. Selon Anthropic, l'utilisation sur claude.ai, Claude Desktop et Claude Code compte dans la même limite d'utilisation. C'est pourquoi le mode claude.ai du widget affiche un seul chiffre pour tous vos appareils et toutes vos applications, et pas seulement pour l'ordinateur sur lequel il tourne.

Est-ce la même chose que « Claude Code Usage Monitor » ?

Non. « Claude Code Usage Monitor » est un outil distinct, en terminal, créé par un autre auteur. Claude Usage Monitor de Gábor Vidovics est un widget de bureau graphique pour Windows et macOS, avec une icône dans la zone de notification, des thèmes et des alertes, et il ne demande aucune ligne de commande.

Est-ce un produit officiel d'Anthropic ?

Non. C'est un outil communautaire indépendant créé par Gábor Vidovics. Il n'est pas affilié à Anthropic. « Claude » est une marque d'Anthropic, PBC.

Dois-je lui donner mon mot de passe ?

Jamais. Sans connexion, il lit le journal local de Claude Desktop. Si vous voulez tous vos appareils, vous vous connectez à claude.ai dans votre propre navigateur – l'application ne voit jamais votre mot de passe.

Windows m'avertit quand je le lance. Pourquoi ?

Parce que le code de l'application n'est pas signé (les certificats coûtent de l'argent ; l'application est gratuite). Cliquez sur Informations complémentaires → Exécuter quand même. Vous pouvez vérifier le téléchargement grâce à son empreinte SHA-256 et lire le code source sur GitHub.

Quels Mac sont pris en charge ?

macOS 12 ou version ultérieure. La carte de téléchargement ci-dessus indique toujours à quel processeur la version actuelle est destinée. La version macOS est toute récente – vos retours sont les bienvenus.

Comment fonctionnent les mises à jour ?

L'application consulte ce site quelques fois par jour. Quand une nouvelle version existe, elle vous prévient ; un clic suffit pour la télécharger, la vérifier et l'installer, puis l'application redémarre. Vous pouvez désactiver cette fonction.

Comment le désinstaller ?

Windows : Paramètres → Applications → Applications installées → Claude Usage Monitor → Désinstaller. macOS : glissez l'application dans la Corbeille. C'est tout.
