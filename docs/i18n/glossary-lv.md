# Glossary – Latvian (lv) – Claude Usage Monitor

## Tone and form of address

- **Form of address: "jūs" (lowercase, plural-polite), imperatives in -iet** (Pierakstieties, Noklikšķiniet,
  Pārbaudiet, Mēģiniet vēlreiz). This is what Microsoft (Windows/Office LV), Apple and Google use in Latvian, so
  the user sees the same voice as in their operating system. "Jūs" is written lowercase in UI text
  (capital "Jūs" is for letters only); at the start of a sentence it is "Jūs/Jūsu" as normal.
- **Commands, menu items and buttons: infinitive** (Atvērt, Aizvērt, Atcelt, Sūtīt, Izvēlēties krāsu…), as in
  Microsoft Latvian menus. Checkboxes: infinitive "Rādīt …" or a noun phrase.
- Short, friendly, confident. No calques ("klikšķināt uz" → "noklikšķiniet uz"), no English words where a
  standard Latvian term exists.
- Numbers + countable nouns: Latvian agreement depends on the last digit (1 fails / 2 faili / 11 failu), so
  counts are written as "Faili: {}" / "Jauni {}" to be correct for every number.
- Percent: "70 %" in running text and notifications (Latvian norm), "{}%" only on the tight panel / tray tooltip. Latvian quotes „…”.
- Dates: "2026. gada 21. septembris" style (genitive after "kopš": "kopš 2026. gada 21. septembra").

## Privacy document name

**"Privātuma politika"** – this is the name used by the big platforms in Latvia (Google, Apple, Microsoft
"Privātuma paziņojums" is Microsoft-specific; Latvian websites, banks and state portals overwhelmingly use
"Privātuma politika"), and the LANGUAGE-NOTES require it. GDPR → **VDAR** (Vispārīgā datu aizsardzības regula),
article reference "VDAR 6. panta 1. punkta f) apakšpunkts". Controller = **pārzinis**, processor =
**apstrādātājs**, legitimate interest = **leģitīmās intereses**, supervisory authority = **uzraudzības iestāde**
(Latvian authority: Datu valsts inspekcija – not named in the text; the English keeps it generic).

## Units

s / min / h / d (SI-style, as in the notes). Panel compact forms: "{}d {}h", "{}h {}min", "{}min".
Elsewhere with a space: "{} d", "{} h", "{} min", "{} s".
